How to Use
  • Edit Shifts: Click any cell to edit shift times (e.g., 8-5, 12-9) or type 'OFF' for day off
  • Add Employee: Click 'Add Employee' to add new team members with roles and availability
  • Auto-Generate: Let the system create an optimized schedule based on employee availability
  • Navigation: Use arrow buttons to move between weeks or click 'Today' to return to current week
